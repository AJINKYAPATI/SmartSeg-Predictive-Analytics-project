# Smart Customer Predictive Analytics

AI-Powered Customer Segmentation & Behavior Analytics Dashboard

---

## Overview

Smart Customer Predictive Analytics is a modern data analytics and machine learning project built to analyze customer behavior, segment customers into meaningful groups, and generate business insights through an interactive dashboard.

This project helps businesses understand:

* Customer purchasing behavior
* Customer value and engagement
* Customer retention patterns
* Customer segmentation using machine learning
* Predictive analytics for better business decisions

The application is developed using Python, Streamlit, and Machine Learning libraries.

# Installation Guide

## Step 1: Clone the Repository

```bash
git clone https://github.com/your-username/your-repository-name.git
```

---

## Step 2: Open Project Folder

```bash
cd your-repository-name
```

---

## Step 3: Create Virtual Environment

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

### Mac/Linux

```bash
python3 -m venv venv
source venv/bin/activate
```

---

## Step 4: Install Dependencies

```bash
pip install -r requirements.txt
```

---

# Run the Project

Start the Streamlit application:

```bash
streamlit run CustomerSegmentation_Streamlit.py
```

After running the command, open the local URL shown in the terminal.

Example:

```bash
http://localhost:8501
```
